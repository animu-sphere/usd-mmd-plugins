# Unmodified-input native viewport review (2026-10-31)

## Scope and evidence owner

Continues the [owner/runtime admission checkpoint](2026-10-31-phase8-inert-joint-admission.md)
through the dedicated `hydra-toon` viewport. The original private PMX and VMD
are read directly, without damping/joint layer opinions, filtered motion or
experimental spring opt-ins. The renderer consumes the installed native
runtime session's retained final snapshots and displays its owner-returned
damping normalization and inert joint records.

The renderer's
[report 112](https://github.com/animu-sphere/hydra-toon/blob/main/docs/reports/renderer/112-2026-10-31-mmd-admission.md)
owns build identities, local package composition, input SHA-256 identities,
reproducible commands, generated regression results and bounded GPU measurements.
It records successful unmodified-input rendering and teardown, unchanged input
hashes and generated resident reset/replay/admission-record checks. No package
publication or dependency-pin change is claimed. Assets, local paths and raw
private diagnostics remain untracked.

## User visual decision

On 2026-10-31 the dedicated native viewport was opened visibly with the same
original private PMX/VMD and live runtime-owned physics. The user confirmed
the visible result. This is acceptance of this scoped unmodified-input viewport
review, following the temporary accommodated preview in the renderer's earlier
evidence. It does not infer that the user exercised every playback control or
reviewed the entire motion.
