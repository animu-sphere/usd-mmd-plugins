# v0.1.0 — the first release

**Tagged:** 2026-09-17 ·
[Release page](https://github.com/animu-sphere/usd-mmd-plugins/releases/tag/v0.1.0)

The first release of `usd-mmd-plugins`, and the first that claims PMX import:
Phases 0–7 of
[DESIGN_POLICY.md §14](../design/DESIGN_POLICY.md#14-phases).

## Objective

Meet the
[first substantial release's definition of done](../design/DESIGN_POLICY.md#141-first-substantial-release--definition-of-done):
a PMX 2.0 or 2.1 model opens directly with `Usd.Stage.Open` as conventional
OpenUSD — mesh, materials, skeleton, skinning, blend shapes, Japanese names —
with nothing evaluated at open, from a parser that links no OpenUSD, built with
`ost` and with plain CMake, and installable from a package. This release goes
past that definition in two ways: every other morph, the rig and the physics
are preserved on the stage too (Phases 4–6), and VMD motion is read and bound
to a model (Phase 7) for the avatar runtime to evaluate.

## What shipped

- **`usdMmdFileFormat`**, the `.pmx` `SdfFileFormat`: `/Asset` Y-up in meters;
  `geo` (mesh, UVs, per-vertex data, material subsets), `mtl` (MMD material
  semantics with unlit-compatible `UsdPreviewSurface` and MaterialX
  `gltf_pbr` graphs), `skel` (skeleton, BDEF skinning, SDEF approximated),
  `morph` (vertex morphs as `UsdSkelBlendShape`, every other type preserved),
  `rig` (IK chains and append relations, unsolved) and `physics` (rigid bodies
  and joints as `UsdPhysics` where it matches, unsimulated).
- **`mmd_inspect`** and **`vmd_inspect`**: what a PMX or VMD contains, as text
  or JSON, without USD.
- **`mmdPmx`**, **`mmdModel`**, **`motionVmd`** and **`mmdMotionBinding`**, plain
  static libraries with no OpenUSD, each an installable CMake package
  ([PACKAGE_CONTRACT.md](../architecture/PACKAGE_CONTRACT.md)) built from the
  source archive; the bundle and both tools link them statically.
- **Release machinery**: [release.yml](../../.github/workflows/release.yml)
  and the product smoke ([README.md](README.md#how-a-release-is-cut)).

The capabilities, feature by feature, are the
[capability matrix](../reference/CAPABILITY_MATRIX.md) at this tag, and the
change by change detail is the [changelog](../../CHANGELOG.md). Distributed
models and motions were imported locally, and those runs are recorded in
[reports/](../reports/).

## Compatibility

- **Stage-contract version:** 1
  ([STAGE_CONTRACT.md §2](../design/STAGE_CONTRACT.md#2-contract-version)).
- **OpenUSD:** 26.08, exactly
  ([DEPENDENCIES.md §1](../architecture/DEPENDENCIES.md#1-openusd)).
- **Platforms:** Windows x86_64, macOS arm64, Linux x86_64, each as the
  OpenStrata `cy2026` / `usd` target with Python 3.13.
- **Packages:** every library is version 0.1.0 with `SameMinorVersion`
  compatibility: `find_package(mmdModel 0.1 CONFIG REQUIRED)`.

## Artifacts

Per target: `usd-mmd-plugins-0.1.0-<target>-plugin-product.tar.zst` (the
bundle and both tools); `usdMmdFileFormat-`, `mmd_inspect-` and
`vmd_inspect-0.1.0-<target>.tar.zst`; a `.manifest.json` for each. Once:
`usd-mmd-plugins-0.1.0-src.tar.gz` and `SHA256SUMS`.

## Known limitations at this release

- Nothing is evaluated: no IK, append transform, morph, physics or motion
  runs anywhere in this repository. A bound VMD is not baked into a
  `UsdSkelAnimation`; that is the avatar runtime's (MOT-O3).
- `.vmd` does not open as a stage; `usdVmdFileFormat` waits for MOT-O2.
- SDEF is skinned by linear blending (C, R0 and R1 preserved); QDEF is
  unverified.
- The portable material graphs are unlit approximations: no toon ramp, sphere
  map or outline is drawn by them — those semantics are preserved for an
  MMD-aware renderer.
- Display frames and PMX 2.1 soft bodies are parsed and not authored.
- One OpenUSD release, and the plain-CMake presets have been run by hand on
  Windows only; macOS and Linux are covered by CI through `ost`.
