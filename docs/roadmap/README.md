# Roadmap

[current.md](current.md) is the sole source of current work status: priorities,
owners, blockers and completion gates. Completed work leaves the roadmap;
evidence lives in dated [reports](../reports/) and shipped scope in
[release records](../releases/README.md).

[DESIGN_POLICY.md §14](../design/DESIGN_POLICY.md#14-phases) defines the stable
Phase 0–10 scope identifiers. Active priorities use P0/P1/P2 in
[current.md](current.md); Phase numbers do not prescribe scheduling.

## Status at a glance

Follow [current.md](current.md#active-gates) for active status and
[CAPABILITY_MATRIX.md](../reference/CAPABILITY_MATRIX.md) for implemented
support. Release-to-Phase history is recorded in
[v0.1.0](../releases/v0.1.0.md) and [v0.2.0](../releases/v0.2.0.md).
This entry retains its heading for existing links; it contains no second
status table.
